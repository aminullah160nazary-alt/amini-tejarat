# امینی تجارت

اپلیکیشن موبایل‌پسند حسابداری معاملات رخت و سمنت برای حاجی مول الدین امینی.

## امکانات
- ثبت مشتریان و شرکت‌های فروشنده رخت و سمنت
- ثبت فروش، خرید، دریافت از مشتری، پرداخت به شرکت و مصارف
- ثبت جداگانه افغانی (AFN) و دالر (USD)
- مبلغ معامله، پرداخت، باقی‌مانده و بهای جنس فروخته‌شده
- مفاد ناخالص و خالص، طلب مشتریان و بدهی شرکت‌ها
- گزارش ماه جاری، سال جاری و تمام دوره
- چاپ رسید، ویرایش و حذف معامله
- تهیه و بازیابی نسخه پشتیبان JSON

## اجرا و نصب در GitHub
فایل `index.html` را در ریشه مخزن GitHub قرار دهید. برای اجرای آنلاین از Settings → Pages استفاده کرده و Branch `main` و پوشه `/ (root)` را انتخاب کنید.

## پشتیبان و انتقال
داده‌ها در مرورگر همان دستگاه ذخیره می‌شوند. برای انتقال به تلفن دیگر، از «ذخیره نسخه پشتیبان» فایل JSON بگیرید و در دستگاه مقصد با «بازیابی پشتیبان» وارد کنید. مرتباً پشتیبان بگیرید.
